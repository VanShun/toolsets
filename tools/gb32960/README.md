# gb32960 — GB/T 32960 协议解析工具包

GB/T 32960.3-2025《电动汽车远程服务与管理系统技术规范》国标车辆报文解析工具，
从 proto_master（PyQt）工程移植为纯 C Win32 实现。

## 功能

- **双版本自动识别**：`##`(0x2323) = 2016 版 / `$$`(0x2424) = 2025 版；
- **完整帧结构解析**：起始符/命令标识/应答标志/VIN/加密方式/数据单元长度/BCC 校验；
- **数据单元全类型**：车辆登入(含BMS/电池包编码)、登出、平台登入/登出、
  实时/补发上报、心跳、未知命令(原始hex)；
- **信息体全类型**：整车数据、驱动电机、燃料电池、发动机、位置、报警
  (28位通用报警标志逐位解析)、电池电压(多包多单元)、电池温度；未知类型展示原始hex；
- **数值换算**：车速×0.1、里程×0.1、电压×0.1、电流偏移30000×0.1、
  温度偏移-40、转速偏移32000、转矩偏移200000×0.1、坐标÷1e6、单元电压×0.001 等，
  特殊值 `0xFE/0xFF` 系列自动标注"异常/无效"；
- **多帧连报**：按帧头长度字段逐帧切分，连续解析整段日志；
- **容错输入**：空格/换行/逗号/冒号/`0x` 前缀/大小写混排均可；自动定位首个起始符。

## 包内结构

```
gb32960/
├── gb32960.c/.h         # 协议解析核心(纯C, 无界面依赖, 直接产出解析报告文本)
├── tool_gb32960.c/.h    # 界面(hex输入区 + [解析|打开文件…|清空|复制结果] + 结果区)
├── entry.c              # 独立运行入口薄壳(合集版不编译)
├── build.bat            # 独立构建脚本(vendor-on-build + 单测)
└── tests/test_gb32960.c # 单元测试(自构造帧验证: 登入/上报/换算/错误路径/容错)
```

## 使用

粘贴 hex 报文或点【打开文件…】加载 `.txt/.log` → 点【解 析】→ 结果区显示
结构化报告（可一键复制）。报文样例可从 `proto_master` 工程或 `getsscom` 的
Record 日志中获取 `[RX]` 行的 hex 部分。

## 独立构建

```
build.bat
```

产出 `bin\gb32960.exe`（单 EXE，零第三方依赖）并自动运行单元测试。

## 与 PyQt 版的差异

- 增加：多帧连报切分、文件加载、打开即解析、结果复制；
- 暂不支持：PyQt 版的规则自定义（协议规则 JSON 编辑器）与历史记录功能。
