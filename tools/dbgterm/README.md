# dbgterm — 调试终端工具包 (ADB 数据源)

toolsets 合集的一个**自包含工具包**：**单窗体主界面**（对标 SSCOM/getsscom 形态）——
菜单栏（文件/连接/视图/帮助）+ 工具栏（连接/断开/清空）+ 接收区主体 + 过滤行 + 发送行 +
状态栏（6 格：状态/RX/TX/过滤/编码/连接态）。ADB 连接配置经"连接"菜单或工具栏
[连接…] 打开模态对话框；数据源以管道子进程方式运行 `adb shell`（如 logcat 流式输出）。
设计方案见包内 `DESIGN.md`（串口数据源为第二阶段，"连接"菜单已留占位项）。

## 包内结构

```
dbgterm/
├── tool_dbgterm.c/.h   # 主窗口: 菜单栏/工具栏/接收区/过滤行/发送行/状态栏
├── adb_dlg.c/.h        # ADB连接配置对话框(路径/设备/自动命令, 模态)
├── adb_core.c/.h       # ADB数据源(管道子进程/设备枚举/自动命令/关闭时序)
├── dbg_source.c/.h     # 数据源统一接口 + 接收环形缓冲(串口源第二阶段实现同接口)
├── dbg_frame.c/.h      # 接收流处理(行装配/UTF-8解码/时间戳, 纯C)
├── dbg_filter.c/.h     # 关键字过滤(6组/三档显示, 纯C)
├── entry.c             # 独立运行入口薄壳(合集版不编译)
├── build.bat           # 独立构建脚本(自动同步 framework + 运行单测)
├── DESIGN.md           # 设计方案(功能形态/功能点/设计概要/里程碑)
└── tests/              # 单元测试(不依赖真机: adb_core用ping流式stub验证)
```

## 产物说明

| 产物 | 类型 | 用途 |
|---|---|---|
| `bin\dbgterm.exe` | GUI（`-mwindows`） | **模块本体**：调试终端窗口 |
| `bin\test_*.exe` | 控制台 | 单元测试（frame/filter/adb_core），供构建脚本自动运行 |

## 使用要点

1. 填写 `adb.exe` 路径（可点【浏览】选择，或留空后点【刷新】自动探测 PATH）；
2. 点【刷新】枚举设备（序列号 · device/offline/unauthorized），下拉选择；
3. 可选填写登录**账号/密码**（设备 shell 登录，形态对标 getsscom；连接后先发账号，
   **延迟"登录延迟(秒)"（缺省 3 秒）**再发密码——设备 shell 的密码提示出现较慢，
   若登录失败可增大该值）；
4. 填写自动命令（缺省 `logcat -v time`，可改如 `logcat -v time -s yaxon`）；
5. 可选勾选**失败自动重登**并配置重登间隔（秒，缺省 10）：连接异常断开后按间隔
   自动重连并重发登录/命令，期间状态栏显示"ADB: 重登中…"，点【断开】随时取消；
6. 点【连接】；接收区勾选"时间戳"加行前缀；"启用过滤"后按组关键字过滤
   （逗号分隔，组下拉切换，显示模式三档，命中行 `>>K<组号>` 标记）；
7. 发送：底部输入框写入命令，勾选"发送加回车"自动补 `\n`；
8. 断开自动走 Ctrl+C → exit → 兜底杀进程时序，设备侧 logcat 随之收尾。

**配置持久化**：连接成功后全部对话框配置（路径/设备/账号/密码/自动命令/重登/登录延迟）
自动保存到 exe 同目录 `dbgterm.ini`（`[Adb]` 节），下次打开对话框自动回填；
点【刷新】后自动选中上次使用的设备；设备下拉也支持直接手输序列号。
注意：ini 中密码为明文存储（与 getsscom 形态一致），请自行注意文件访问权限。

**接收缓存与日志保存**（文件/视图菜单）：

- 视图 → 接收缓存：显示缓冲档位 256KB/512KB/1MB/2MB/4MB（单选，立即生效并持久化
  `[View] RxCacheKB`，超限自动裁头；内部环形滑动缓冲固定 8KB 为节流窗口）；
- 文件 → 自动保存到文件：开启后接收流持续追加写入保存文件夹
  （`dbgterm_auto_<时间>.txt`，UTF-8 带 BOM，含时间戳行；状态栏"保存: 开/关"联动，
  持久化 `[Save] AutoSave`，程序启动自动恢复）；
- 文件 → 立即保存…：接收区当前内容一次性快照落盘（`dbgterm_<时间>.txt`）；
- 文件 → 设置保存文件夹…：浏览选择输出目录（持久化 `[Save] Dir`），
  缺省为 exe 同目录 `Record\`（不存在自动创建）；
- **过滤窗口同款保存**：工具行 [自动保存]（勾选，持久化 `[Save] FltAutoSave`）
  + [立即保存]——命中行写入 `dbgterm_flt_auto_<时间>.txt` / 快照 `dbgterm_flt_<时间>.txt`，
  与主通道共享保存文件夹、独立开关。

## 独立构建

```
build.bat
```

- 产出 `bin\dbgterm.exe`（单 EXE、零第三方依赖；adb.exe 为外部工具，按需自备）；
- vendor-on-build：构建时自动从 `..\..\framework` 同步 `ui_common` 源码到包内
  `framework\`（该副本已被 gitignore），整个目录拷走后任意 MinGW 环境可直接构建。

## 集成进 toolsets 合集

已完成登记（`app\tool_manifest.c` "调试终端"卡片）；合集版主界面点击卡片即打开。

## 依赖

- `framework\ui_common`（共享字体/圆角矩形/剪贴板/图标），经 vendor-on-build 同步；
- 系统库：gdi32、user32、comdlg32（浏览文件对话框）；
- 外部工具：adb.exe（Android platform-tools，用户自备并配置路径）。
